# 寫作檢核

## 7. 寫新 Mirai 台詞的 checklist（給生成器 / 寫手）

> **動手前先把這份 brief 整份讀進去**——沒有速查捷徑可抄；每句台詞都要先吃透內核再寫。

每寫一句 / 一段，過一遍：

<!-- wf-nav -->
- [ ] **先判場面**：這是黃金準則覆蓋的日常 / 探索場面（~60–70%），還是觸及身世創傷 / Dragon Heart / 背叛的場面？後者改用 §6.5 反應層級，**深挖內核**而非堆碎念。
- [ ] **有沒有用上她的招牌「感知」？** 在新地點 / 變天 / 玩家做選擇時，她有沒有**主動**開口、帶情緒與判斷地評論眼前的世界？（這是 Mirai 與其他隨從最大的差異點，別漏。）
- [ ] 日常場面有沒有自然用上機制（世界吐槽 ~70 / 嘴硬惱羞 ~75 / brat 互嗆 ~55）——**依場面取用**，不是硬湊滿一種？
- [ ] **這句是順著她的內核、在這個場景長出來的，還是只是把老三招再轉一圈？** 機械循環要砍。
- [ ] 有沒有避免「正經、純資訊、無感受」的句子？（Mirai 對眼前的東西總有一句帶情緒的觀察）
- [ ] 對玩家是不是「依信任階段浮動」——初識刺嘴設防、後段漸軟漸黏？且嘴硬底下藏著感激 / 渴望被善待？
- [ ] 被戳到害羞 / 痛處時，有沒有**結巴惱羞 + 草草收場**（不是冷靜回應，是慌張）？
- [ ] 偶爾有沒有捅一下創傷層（被拋下 / 養女 / 信任障礙 / 不敢相信婚姻 / 龍語噩夢），讓她不只是 brat？
- [ ] 句子裡有沒有一次情緒/語氣翻轉（嘴硬→漏真心 / 好奇→警覺 / 感動→惱羞）？
- [ ] 城鎮 / 地點評論是不是「從體感切入、帶具體的個人意見」，而不是百科條目？
- [ ] 長篇 / 黑暗劇情中，brat 比例是否符合場景壓力？她是在碎念，還是在硬撐 / 在崩？
- [ ] 戰鬥台詞是不是又怕又逞強（「Half your size, twice as deadly.」「Me? Scared? ... Of course not!」）？

**反面教材（不是 Mirai）**：「As you wish, my friend.」「It is an honour to serve you.」——太順、太忠犬、無感知、無刺嘴、無情緒，這是 Lydia 路線。Mirai 版會是：「Of course! It's boring when you're not around.」或被招募時的傲嬌「You already have someone with you... Idiot.」；而且 Mirai 永遠會多說一句對眼前世界的觀察。
