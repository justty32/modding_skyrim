# Onean 性格分析 — 寫作 brief（來源：Follower Onean 對白抽取）

做 Onean 擴充時的**角色聖經 / writing brief**：要產出「聽起來像 Onean」的新台詞，先吃透這份。

**來源說明（重要）**：原始 `Onean/dialogue.md`（標題寫 English）其實是**雙重 mojibake 的簡體中文**，內容與官方繁中 `Onean_CHT/dialogue.md` 完全一致；本 mod **沒有真正的英文原文**。因此本文所有引用都用**繁中原句**（=遊戲內實際對白），這是唯一忠實的依據。對白總量很少（一個 Hello topic + 一條 Idle + 一段母親護符對話 + 大量「換裝/購買」機械 INFO），所以下面凡是推斷處都標明**可推斷到的程度**，不硬掰。

對白規模：~50 個 topic，但其中約 35 個是**換裝 / 購買護甲衣服**的功能性 INFO（回應幾乎都是「如你所願」「我知道了」「你的錢不夠」），人設訊息量**極低**；真正承載性格的只有 Hello / Idle / FirstHello 招募 / 治療 / 藥劑(調情) / 解雇 / 母親護符這幾組。
