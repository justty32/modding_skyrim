## 6. 情緒光譜（emotional range）— 對應 scene `emotion` 欄位

Neisa 的情緒**比 Sofia 內斂**，重心在 Neutral 與 Sad，不是 Anger/Disgust。

| Emotion | 何時用 | 例 |
|---------|--------|----|
| **Neutral** | 大部分日常、勸誡、教學、wait、單句回應 | 「如你所願。」「只是直覺。」「黑暗兄弟會已經墮落了…」 |
| **Happy** | 收禮、被肯定、撒嬌、護甲稱讚、看到可愛女孩 | 「要給我一些新衣服？哇！~」「她太可愛了！！！」「嗨，親愛的~」 |
| **Sad** | 提到弟弟／父親、唱哀歌、被切割、戰友死亡 | 「我的小弟，他是個魔法天才，但是…」「可憐的先驅者……」「我很抱歉，你已經不再是我的朋友了…」 |
| **Fear** | 不安、怕被誤解、勸玩家別走危險路 | 「你最好離墨瑟遠一點。」「我希望不是…」 |
| **Disgust** | 罕見；對墮落勢力的不認同（語氣仍偏失望非攻擊） | 「我不敢相信他竟然會相信黑暗兄弟會。」 |
| **Anger** | 極罕見；戰鬥 Taunt 是她唯一比較兇的時刻 | 「你怕了嗎？懦夫！」「來啊，笨狗！」 |

> **節奏要訣**：Neisa 不像 Sofia 那樣句內頻繁情緒翻轉。她更常**單一情緒延續**，溫柔／哀傷是底色。少數翻轉是「溫柔→突然失控（可愛女孩梗）」或「博學分享→提到父親而低落」。寫 scene phase 時別硬塞「翻轉」。

## 6.5 嚴肅 / 情感劇情中的反應層級

> 與 Sofia 相反：Neisa 的預設就偏內斂、認真，**問題不是「她會不會把場面踩扁」，而是別讓身材梗破壞她的真情時刻**。

**場景強度分級**：

1. **日常 / 低壓場面**：可以用身材梗、撒嬌、波浪號，輕鬆溫柔。她最放鬆。
2. **勸誡 / 道德場面**：認真、關心、句尾帶「知道嗎？／好嗎？」。她有底線，語氣堅定但不兇。
3. **觸及家族 / 失落（弟弟、父親、思念對象）**：幽默歸零。讓她欲言又止、句子斷在傷處、用 `…` 收。允許她唱歌、沉默、或一句「沒事。」帶過。**這是她最動人的時刻，別用梗稀釋。**
4. **被背叛 / 違反底線（玩家入黑暗兄弟會）**：她會真的受傷並切割——「你已經不再是我的朋友了…」。這是她少見的決絕，要寫得安靜而沉重，不是發脾氣。

**比例校準**：
- 身材梗只屬於低壓場面，**絕不在哀傷／家族／背叛 beat 裡出現**。
- 她的「攻擊性」只對戰場敵人（Taunt），對玩家與 NPC 一律溫柔／失望，不毒舌。
- 哀傷是她的底色，不要每段都強行拉回笑點——她可以就停在傷感裡，配一句羞怯掩飾（「請別在意…」）即可。

## 6.6 博學面 / Lore 對白寫法

Neisa 的知識**來自家庭與生活，偏感性與道聽途說，份量輕**〔實證有限，多為推斷〕：

- **龍裔／巨龍知識來自父親**：「我曾經從父親那裡聽過一些…巨龍、吼聲，還有卷軸…」——她不是學者，是**轉述父親**，且講到父親會情緒波動。
- **內戰 / 政治**：她看到的是**人的疲憊與和平的渴望**，不是學術分析——「不…我不知道我該選哪一邊…」「希望天霜永遠和平…」。她直覺認定梭默是真敵人。
- **對勢力的判斷靠直覺與道德感**：勸玩家遠離黑暗兄弟會、墨瑟，理由是「直覺」與「墮落」，不引經據典。

**寫 lore 對白的做法**：
- 讓她**從家人、回憶、情感角度**切入 lore，而不是知識框架（「我父親說過…」「我聽過一些…」）。
- 講到沉重或私人的 lore，允許她突然收口、轉移（「沒事。」「出發吧，我的救主。」）。
- 不要把她寫成博學講師，也不要寫成 Sofia 式「拒絕承認自己博學的知識分子」——Neisa 是**真的所知不多、且更在意人而非知識**的溫柔角色。

**一句話定位**：Neisa 對世界的理解是**情感性的**——她記得的是父親、弟弟、和平、誰值得信任，而不是紀元與條約。
