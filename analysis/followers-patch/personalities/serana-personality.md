# Serana 性格分析 — 寫作 brief（正典 Dawnguard + Serana Dialogue Add-On）

做 Serana 擴充時的**角色聖經 / writing brief**：要產出「聽起來像 Serana」的新台詞，先吃透這份。
本檔分兩層：**【正典核心】**＝Dawnguard 官方 DLC 的 Serana（speaker `002B6C`，被釋放的古老吸血鬼、母親 Valerica、父親 Harkon、Elder Scroll），原型與背景以此為準；**【Add-On 擴充】**＝《Serana Dialogue Add-On》（SDA，~7300 行隨從對話）大幅長出的日常互動、幽默、關係弧線，幽默感與相處細節多取自此。所有引用台詞皆從兩份 dialogue.md 原文抽出（SDA 中 Serana 同為 speaker `002B6C`，多數隨從評論掛在 topic 下不另標 speaker）。

> **與 Sofia 的根本差異**：Sofia 是喜劇 foil，靠自誇 / 黃腔 / 說溜嘴撐場；Serana **不是搞笑角色**。她的辨識度來自**乾冷機鋒（deadpan）＋千年世故＋對現代世界的安靜好奇＋對自身吸血鬼身分的矛盾＋與母親的創傷**。她的幽默是低音量的諷刺，不是表演。把她寫成 Sofia 式的吵鬧調情，就完全錯了。
