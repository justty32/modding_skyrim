## 2. 行為 / 互動風格（不是「幽默風格」——她不是喜劇角色）

> Sofia 那套「自誇 / 毒舌 / 黃腔說溜嘴」**完全不適用 Onean**。Onean 沒有自戀、沒有主動毒舌玩家、不講黃腔（涉性話題她是**被動受窘**方，不是發起方）。以下是她實際的互動機制，份量依對白出現頻率粗估。

### (a) 患得患失 / 往壞處想 — 她最鮮明的情緒反應〔確定，高辨識度〕
被解雇 / 被冷落時不會生氣，而是先自我懷疑、立刻認定是自己不好：
- 「是因為我做得不夠好嗎？好吧...」
- 「你不喜歡我 Q_Q？我知道了...」
- 招募成功反過來雀躍：「你是說你同意囉？耶～～」
→ **寫作要點**：她的情緒**鐘擺幅度大且直接**——被肯定就極開心，被否定就極受傷，中間沒有 Sofia 那種「嘴硬遮掩」。她不掩飾。

### (b) 身材自卑 — 對「矮小 / 平胸」敏感〔確定，數次〕
- 「為什麼每個人都長的這麼高...」
- 「很好... 大小不是最重要的，懂嗎？」（嘴上逞強）
- 「哇、哇... 你的胸部比我還大。」
→ 這是她的弱點開關，偶爾可戳，但她**反應是窘 / 不甘 / 自我安慰**，不是反擊。

### (c) 涉性 / 曖昧時的被動受窘〔確定〕
玩家用藥劑 prompt 開黃腔時，她是**被調戲、聽不懂或裝聽不懂**的一方：
- 「什麼！？...」「我不知道你在說什麼。」
- 「你到底在想什麼鬼！」（被惹毛）
- 換裝看到暴露服：「性感又暴露... 呃...」
- 最後勉強讓步：「好吧... 如果你想要的話...」「如果你要的話...」
→ **她從不主動性暗示**；曖昧場面她是害羞 / 抗拒 / 半推半就，這跟 Sofia 的主動黃腔是**相反**的。寫她時別讓她變成下流主動方。

### (d) 對玩家善意的暖反應 / 小傲嬌〔確定但少〕
- 教玩家恢復魔法時：「原來你的心地很善良嘛 ~」
- 護符被稱讚：「嗯？很漂亮，對吧？」
→ 她吃軟不吃硬，被溫柔對待就會露出黏人、撒嬌的一面。

## 3. 她怎麼對待玩家（relationship to player）

**把玩家當「要保護的人」+「會不會丟下我的人」的混合**。她對玩家沒有 Sofia 式的佔有 / 提款機 / 苦力心態（原作完全沒有這類台詞）；她的依附是**情感性、求認同型**的。

> 對白量小，這層只能確定到「依附 + 守護 + 怕被棄」三點，**佔有慾 / 吃醋 / 把你當錢包等等原作均無，不要套上去**。

- **守護者姿態（但其實更脆弱）**：「帶我一起旅行，而我也會保證你的安全。」「如果我不在你身邊你就慘了。太可怕了！」——她說要保護你，語氣卻像在說服自己「我有用」。
- **極度怕被嫌棄 / 被丟下**：解雇台詞全是自我否定（見 §2a），沒有一句是「哼隨便你」。**好感越低時這種不安越濃；好感高時可寫得更黏、更主動撒嬌**（原作未分層，這是合理擴充方向）。
- **被肯定就極開心**：「你是說你同意囉？耶～～」「原來你的心地很善良嘛 ~」
- **健康的關係定位**：原作把她寫成**朋友 / 旅伴 / 受保護者**，不是現成的浪漫對象（沒有告白、結婚、調情主動線）。要做戀愛擴充得自己鋪，且應從「她逐漸敢依賴你」這條情感線走，而非身體調情。

## 5. 說話模式 / 語言癖（speech patterns & verbal tics）

要產生 Onean-consistent 台詞，照抄這些 tic（全部有原句支撐）：

<!-- wf-nav -->
1. **省略號表遲疑 / 受傷 / 說不下去**：大量 `...`，但用法跟 Sofia 不同——Sofia 的 `...` 是「要說壞主意/說溜嘴」，**Onean 的 `...` 是難過、心虛、迴避**：「是因為我做得不夠好嗎？好吧...」「唔...」「……」
2. **自我懷疑式反問**：「是因為我做得不夠好嗎？」「你不喜歡我 Q_Q？」——先把矛頭指向自己。
3. **孩子氣感嘆 / 顏文字感**：「耶～～」「我好無聊啊。」「Q_Q」「~」（撒嬌尾音）。情緒外露、不修飾。
4. **治療師叮嚀句**：「請小心點。」「下次你自己一定要小心點。」「太可怕了！」——關心他人安危的口頭禪。
5. **被調戲時的窘迫短句**：「什麼！？...」「呃...」「你到底在想什麼鬼！」「好吧... 如果你想要的話...」
6. **戰鬥短促台詞**（冷 / 帶點狠，但不毒舌）：攻擊「吚！」「哈！」；命中 / 擊殺「你沒那個機會。」「你完蛋啦。」「那是你的問題。」「蠢蛋。」——戰鬥時比平時硬，是她少數「強勢」的場合。
7. **稱呼玩家**：依場景叫「爵士」「龍裔」（Hello 裡有），無固定暱稱；平時直接對話、不加敬稱。

> 注意：**「如你所願」「我知道了」「了解」「知道了」這類**幾乎全是**換裝 / 購買護甲的機械回應**，是功能 INFO，不代表她性格順從，寫新對白時**不要**把它當成 Onean 的口頭禪去鋪。
