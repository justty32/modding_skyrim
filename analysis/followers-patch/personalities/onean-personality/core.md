# 定位、原型與背景

[返回入口](../onean-personality.md)

## 0. 一句話定位

**Onean 是一個嬌小、孩子氣、黏人又帶著喪母陰影的天霜治療師（healer follower）**——她最辨識的幾點是「自稱治療師、把守護玩家當己任」「對自己身材矮小/平胸的自卑」「被冷落時立刻往最壞處想、怕被丟下」，外殼是天真愛玩、偶爾耍嘴的小女孩，內核是失去母親、渴望被需要、怕自己不夠好的不安全感。她不是毒舌喜劇 foil（那是 Sofia），也不是高冷戰士；她是**會擔心你受傷、會因為你一句嫌棄就垂頭喪氣、私下喊「媽…」的治療系少女**。

> 對白量太少，無法支撐「招式循環」式的人設清單。寫擴充時的核心工作是**從這幾個確定的內核點往外長**：① 治療師身分與守護慾；② 喪母 / 思念母親；③ 身材自卑與「想變更強」；④ 孩子氣的患得患失。把她丟進新場景時，問「**以這四個內核，她在這裡會怎麼反應**」，而不是套任何固定笑點。

寫新台詞的準則：**讓每句話至少能掛到上述某個內核**——治療師的關心、對被丟下的敏感、孩子氣的情緒外露、或對母親的隱痛。純功能、純資訊的句子（「如你所願」那類）只適合純機械操作，不要當成她的性格代表。

## 1. 核心原型（archetype）

**治療系少女隨從 / caretaker-but-needy**。她的功能定位是「治療師」，但人格上她比玩家更像需要被照顧的一方——這個**照顧人 vs 渴望被照顧**的張力是她最核心的東西。

- **治療師自我認同**〔確定，多次出現〕：自我介紹就是「我是奧妮安。而且當然了，我還是個治療師。」招募話術是「帶我一起旅行，而我也會保證你的安全。」——她把「保護你」當成自己的存在價值。
- **守護慾 / 像母親般叮嚀**〔確定〕：治療你之後會唸「好... 但下次你自己一定要小心點。」「如果我不在你身邊你就慘了。太可怕了！」Hello / 道別也反覆「請小心點。」「小心點 ~」——她真心怕你出事。
- **孩子氣、情緒寫在臉上**〔確定〕：Idle 會無聊抱怨「我好無聊啊。」、唱歌、自言自語「還得變得更強...」；答應招募時「你是說你同意囉？耶～～」。語氣天真、不設防。
- **想變強 / 有點不服輸**〔確定但淺〕：Idle 的「還得變得更強...」是她少數的自我期許線，可作成長鉤子，但原作沒展開，**不要過度解讀成戰鬥狂**。

## 4. 不安全感 / 背景鉤子（insecurities & backstory）〔這層是 Onean 最有料的地方〕

她的對白量雖少，但**喪母**這條背景線是明確、且情感重量最大的鉤子。擴充最該深挖這裡。

<!-- wf-nav -->
- **母親已逝 / 思念母親**〔確定，唯一成形的背景線〕：護符對話一步步揭開——
  - 「這是我母親的護符。」
  - 「但是她再也看不到我戴上它了。」（暗示母親已不在）
  - 玩家追問「為什麼？」→ 她只回「唔...」，再追→「……」（**說不下去，迴避**）
  → **寫作要點**：母親是她的痛點與沉默處。涉及母親時她會**語塞、迴避、安靜**，不是大哭也不是嘴硬。這是擴充任務最自然的主線鉤子（母親身上發生了什麼？護符的來歷？）。
- **獨自喊「媽」**〔確定〕：Idle 獨白「我該怎麼辦.. 媽...」——獨處放空時會不自覺想起母親、像在求助。這是她孤獨內核的直接證據。
- **身材 / 不夠強的自卑**（見 §2b、§1）：「為什麼每個人都長的這麼高...」「還得變得更強...」——她覺得自己又小又弱，想證明自己。
- **怕自己不被需要**：解雇反應（§2a）顯示她把「被留在身邊」等同於「自己有價值」。

> 推斷邊界：除了「母親已逝 + 自己是治療師 + 嬌小想變強」，原作**沒有**交代她的種族、出身、年齡、師承、為何流落天霜等。這些都是**空白可填**，但別當成既有設定引用。
