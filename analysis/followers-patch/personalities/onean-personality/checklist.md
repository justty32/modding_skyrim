## 7. 寫新 Onean 台詞的 checklist（給生成器 / 寫手）

> **動手前先把這份 brief 整份讀進去**，並牢記：**Onean ≠ Sofia**。沒有自戀、沒有主動毒舌玩家、沒有主動黃腔、沒有佔有慾錢包心態。

每寫一句 / 一段，過一遍：

<!-- wf-nav -->
- [ ] **這句掛得到哪個內核**？治療師守護慾 / 喪母隱痛 / 身材自卑想變強 / 孩子氣患得患失——掛不上任一個的，多半不像她（純功能句除外）。
- [ ] 情緒是不是**直給、不掩飾**？（Onean 不嘴硬遮掩；開心就 happy，受傷就 sad，被惹毛就 anger）
- [ ] 對玩家是不是「**求認同 + 想保護你**」而非「嫌棄 / 佔有 / 把你當工具」？
- [ ] 涉性 / 曖昧場面，她是不是**被動受窘**方（害羞 / 抗拒 / 半推半就），而**不是**主動性暗示？
- [ ] 有沒有誤用 Sofia 招式（自誇 / 毒舌玩家 / 主動黃腔 / meta）？有就刪。
- [ ] 戰鬥台詞是不是又短又冷、帶點狠但不長篇毒舌？（「你完蛋啦。」「蠢蛋。」）
- [ ] 治療 / 危險場景，有沒有讓她的**守護師本能壓過恐懼**？恐懼是否指向「救不了你」？
- [ ] 觸及母親 / 死亡 / 失去時，有沒有用**語塞、沉默、迴避**（「唔...」「……」），而不是台詞填滿？
- [ ] 省略號是不是用在**遲疑 / 難過 / 說不下去**（Onean 用法），而非「要說壞主意」（Sofia 用法）？
- [ ] 有沒有保留她孩子氣的感嘆與撒嬌尾音（「耶～～」「~」「Q_Q」「太可怕了！」）？

**反面教材（不是 Onean）**：「我美得不講道理，規則對我無效。」「你又想用我當提款機？」「想被我撩到語無倫次嗎？」——自戀、佔有、主動調情，這是 **Sofia** 路線。Onean 版會是：「你受傷了？讓我看看…別亂動，我幫你治。」「你…你不會把我丟下吧？我會乖乖跟好的。」
