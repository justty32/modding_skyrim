## 與既有星盤的關係

既有[27 atoms與49文字映射](../design.md)仍負責把PoE原句拆成份額；本題處理的是戰鬥事件規則，不能把49條converter規則誤認為已有49種runtime觸發。星盤主圖1993個可購買節點的既有分母不變，本輪沒有新增節點、重新分配份額或宣稱全圖都已承載這些玩法。

[已定裁示](../decisions.md)的每級1點、1／3／5份、既定每份整數、無runtime caps與速度離線設計檢查均保留。條件增傷不可直接冒用DMG_1H每份3%；新效果須有自己的預算與校準，才討論放到哪些節點。來源原倍率也不是本案核定值。

本案以來源機制作靈感：Cross Cut的同目標標記接重擊、Clash of Champions命中削弱、Skull Rattler耐力讀值與Bastion團隊防護；可查[既有過目頁](../../../../user/2026-11-03-perk-units.md)。本案的回擊／護援規則是新組合，來源並未證明已具備本案全部事件與選人能力。
