## 逐件：圖上是什麼 → 現有件怎麼改

改法分三類：**貼圖**（texedit 就能做，回家拿到真貼圖照這張單寫操作清單）、**網格**（階段 M，要家裡的工具）、**新件**（要建模）。

| 部件（[pieces.json](data/pieces.json) id） | V6 圖上 | 改法 |
|---|---|---|
| shirt 上衣 | 灰色無袖襯衫、白領、胸前一道暗色口袋縫 | **貼圖**：主片轉 `#A1ADBB`、領子轉白、口袋縫畫暗線。**網格**：寬袖要剪成無袖（sleeveless，M 階段）。原計畫 Corset 上青綠帶那版不照 V6，V6 沒有束腰 |
| skirt 裙 | 黑短百褶、褶內露青綠、左前有青綠圓點陣列 | **貼圖**：底色藍轉黑 `#151E22`；褶線內側上 `#14CED5`；圓點陣列用 texedit 的 decal 貼。能不能對到褶，要回家看 UV 疊圖。**網格**：輪廓與長度待驗（pleats） |
| 腰帶 | 黑帶、扣子青綠＋洋紅小方塊 | 裙的腰帶帶：**貼圖**轉黑，扣子位置貼一小塊 decal |
| sleeves 袖套 | 黑長袖套、口緣青綠、外側一排指示燈與小顯示面板 | **貼圖**有障礙：UV 跟遠端金屬面幾乎全共用（6,709／6,717 texel），改了金屬也會變。要先**網格**拆 UV 或分材質，之後黑底＋青綠口＋面板 decal 才做得到 |
| boots 長靴 | 黑大腿長襪＋黑短靴、襪口青綠帶 | **貼圖**：主體轉黑、靴口帶上 `#14CED5`（試色已驗帶外 0.27%） |
| ribbon 髮帶 → ornaments | 雙尾根部的黑色髮束（V6 不是紅黑方塊） | 現有單一髮帶**貼圖**轉黑＋一道青綠即可接近；要左右成對得**新件** |
| tie 領帶 | 青綠領帶 | **新件**（Blender 程序化建模，mesh.md 已排） |
| headset 耳機麥克風 | 黑灰耳機＋麥克風 | **新件**（mesh.md：TripoSG 草模或程序化） |
| tattoo 左上臂 01 | 洋紅「01」 | 無袖之後才看得到；做法是身體貼圖 overlay（RaceMenu overlay），不改衣服 |
| 指甲 | 青綠 | 不在服裝範圍；RaceMenu 指甲 overlay，另議 |

## 先後

1. **回家第一輪（只靠貼圖，一晚內）**：裙、靴、腰帶、上衣主片與領子、髮帶轉黑。全部走 texedit：拆開 → 看 UV 疊圖對部件 → 寫操作清單 → 裝回 → 預覽 → staging。裝層、進遊戲照舊要使用者當場說。
2. **第二輪（網格）**：上衣剪無袖、袖套拆 UV。走 Outfit Studio MCP（[mesh.md](mesh.md) 階段 1，要 D1）。[mc-skin](../../../../agentctl/handoffs/home-2026-11-26/mc-skin/REPORT.md) 查過：model-converter 不帶骨骼與權重，蒙皮衣服轉不了，補要 6–9 天，不走。
3. **第三輪（新件）**：領帶、耳機、成對髮飾。
