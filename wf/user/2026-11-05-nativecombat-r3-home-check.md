# NativeCombat r3：回家自然實戰觀察

r3已部署，三項實戰仍未驗。回家照原本方式玩一段就好，先確認MO2選的是 `modpack-main`，用MO2的SKSE入口開遊戲，不從Steam啟動。讓agent先核版本與本次證據窗；選你目前適用、隊伍與能力仍在的存檔，不必為此重開新檔。

這次最多20分鐘或兩場自然遭遇，不為測試改角色、換role、補技能或刻意引戰，只看三件事：

- **普通選裝**：隨從能正常自行用武器/手持法術攻擊，沒有反覆收拔或強制換裝。
- **治療圈**：原本就有的能力自然發動時，適用成員會進圈/留圈且仍正常攻擊；圈結束後恢復正常移動。
- **Volley**：原有適用Archer/Mage自然發動、又沒有治療圈時，能跟隨能力目標攻擊；結束後不殘留牽制。

沒自然發動就記「未驗」，不用追著測；只看到載入成功或native enabled也不算通過。這次只驗現有r3，不推進星盤候選，也不重開Varinia已結案問題。

若出現反覆收拔、卡住不攻擊、圈結束還走不開、崩潰或卡死，先停下，記角色、時間、當時能力與目標，留畫面或簡短具體描述；讓agent保存當次log，別急著重開蓋掉證據。測試結束不要覆寫原存檔，也不要自行撤層或改設定。

操作與機器可填清單見[回家準備](../../agentctl/handoffs/home-2026-11-05/nativecombat-r3-ready/README.md)；已部署及原有未驗界線見[11-02報告](../../agentctl/handoffs/home-2026-11-02/nativecombat-default-deploy/REPORT.md)。這是回家指南，沒有宣稱實機通過。
