# 劍盾可以玩出什麼樣子

先從角色幻想選玩法，再決定用哪些規則組起來。推薦先看**轉鋒、守線者、開門人**：分別把決策放在「打誰」「守哪裡」「讓誰接棒」。另有藏鋒、決鬥盾、戰地救護三個替代方向。都是可混搭的設計提案，不是互斥職業或新職業選單；數值、代價與強度尚未定。

## 攻擊 轉鋒

**盾打開缺口，劍決定收掉這個敵人，還是把勝勢帶往下一人。**

普劍A試探 → 盾擊A取得劍勢 → 重擊A兌現；也可改普擊B，把破綻搬給B、開始下一輪。換人只搬目標，不疊強度，不能靠空揮或屍體反覆取勢。會在意單手傷害、耐力和回復，但最重要的選擇是繼續殺強敵，還是先拆包圍。

例如替隊友在A身上留開門標，自己轉鋒去B，就是攻擊與輔助的合作，而不是每次都做固定三連。畫面只需一份劍勢提示與當前敵標，不先新增計量表。

**替代：藏鋒。** 真正擋過一次危險攻擊形成勢，持盾暫不揮劍；新真格擋以最近交鋒壓力替換舊勢，下一次劍擊整筆兌現，也可提前出手救急。停止接戰便失去來源。不是戰外等時間疊爆發，也不是越等無限強。適合喜歡讀敵人節奏、忍到對的時機再出手；靈感是方舟[解放者的準備期與釋放期](https://prts.wiki/w/玛恩纳#特性)，本案不用照搬它的阻擋0或數值上限。

## 防禦 守線者

**我選擇哪一片戰場值得守，不必等AI願意打我。**

真格擋在腳下立一個可見守勢錨 → 留在圈內持盾，保護自己和附近友軍 → 出圈追敵或主動重擊就撤守。下一次真格擋能重新立錨，但舊錨消失，不能鋪滿地。

敵人後退時，你要留著護後排，還是放棄掩護去追遠程？這一路重視站位、格擋、生命容錯與耐力。防護是友軍效果，不是替他們攔截實體傷害；solo也有留地抗壓／出圈追擊的取捨。與轉鋒混搭時，追擊真的會撤守，兩路不會沒有代價地全拿。

**替代：決鬥盾。** 記住真正擋過的單一敵人，對他的後續攻勢更能抵禦；轉而盾擊／追擊另一人就放棄專注。適合與強敵周旋，不是守一整圈。方舟[決戰者在交戰限制下取得回報](https://prts.wiki/w/森蚺#特性)提供靈感，但方舟阻擋不等於Skyrim格擋，也不等於能控制敵人仇恨。

## 輔助 開門人

**盾替隊友打開門，好處給真正跟上的人。**

盾擊指定敵A放援攻標 → 自己普劍牽制、不搶吃 → 隊友或召喚物先命中A，恢復該命中者的一種資源。HP、SP或MP先選一個版本，不全部包辦。自己若先重擊A，可以提前收招取得個人收益，代價是放棄這次支援。

看隊友位置，判斷替哪個敵人開門；不用砍隊友、不讀AI正在追誰，也不自動替你挑最低血的人。隊友打B不吃A標，滿資源而無實際收益時不吞標也不付款。帶隊或召喚最鮮明；solo只保留明示的重擊退路，不暗改成同額自補。

方舟[教官](https://prts.wiki/w/帕拉斯#特性)與[戰術家](https://prts.wiki/w/豆苗#特性)把回報綁在自己與同伴的交戰分工；「隊友先命中接棒」則是本案原創轉譯。[瑕光個人技能的攻擊治其他友軍](https://prts.wiki/w/瑕光#技能)也能作進攻救人的靈感，並非所有守護者都有這個技能。

**替代：戰地救護。** 先攻敵備好救護，再收劍持盾靠近隊友，暫停輸出進入救護；拔劍便中止。比開門人更像前線醫護，必須主動放下進攻機會。參考[護佑者攻擊／治療轉態](https://prts.wiki/w/月禾#特性)與[吟遊者不攻擊換範圍支援](https://prts.wiki/w/浊心斯卡蒂#特性)，不照搬技能鍵、部署範圍或倍率。

## 先選幻想 再選數值

三個主案的混搭可以是：守線時替圈邊敵人開門；轉鋒去另一敵，讓隊友接走原敵的援攻標。藏鋒與救護同時都少輸出，卻不能重複兌現同一份準備。不是把六套被動全塞在一個人身上。

真正共用的是事件、對象、條件、值函數與狀態生命週期。HP／MP／SP可讀值、支付和恢復；抗性／負重也可比較與縮放，但不能因為是數字就拿來當魔力扣。門檻回答能否發動，連續函數回答有多強。新案需要的actor歸屬、位置錨／範圍、隊友原生命中與可見提示仍待引擎驗證，沒有宣稱已有實現能力。

既定星盤的每級1點、1／3／5份、27基本效果與49條文字映射不改，也不增加runtime上限。先挑喜歡的操作與取捨，再校準新規則成本、持續與份數，討論放在哪些節點。方舟來源是PRTS社群資料，分支特性與個別幹員技能分開引用，數值不移作本案定案。
