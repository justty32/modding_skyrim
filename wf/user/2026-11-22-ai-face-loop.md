## 你之後怎麼下需求

可以直接貼給 agent 的範例：

> 照 racemenu 工作流幫我捏臉：以 Hatak 為底，臉瘦一點、下巴尖一點、鼻子小一點、妝淡一點。每輪 3 份候選，用 face_loop 拍正面和斜面，挑一份再調一輪，最後給我對照圖。不要部署到 NPC。

要準備的：

- 底：一份 preset（`.jslot`），或說「用某個 NPC 現在的臉」（後者的轉換工具還沒做）。
- 你不在電腦前，或明說可以讓 agent 操作遊戲視窗（它會送鍵盤滑鼠）。

大概多久：開一場約 2.5 分鐘，之後每份 15–35 秒；一輪 3 份加底圖約 4–5 分鐘；三輪約 15–20 分鐘，一場內做得完。

## 還做不到的

- 細調看不準：同一份 preset 重拍，畫面約 10–30% 的像素不同（待機晃動、頭會轉向相機）。
- 真側面：留在 RaceMenu 裡拍時頭會追相機；關掉 RaceMenu 用自由相機拍角度對，但相機每次停的位置不固定。
- 原版沒有「眼睛上揚」「眼睛變大」這種連續滑桿，只能換眼型編號。
- 妝淡一點：jslot 工具可以把戰紋、眼線、唇色的透明度調低（候選檔已做），**還沒在遊戲裡看效果**。
- 男性校準、示範輪、挑選頁都還沒做。
